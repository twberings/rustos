# Research
This directory contains research documents that explain the concepts and design decisions behind RusTOS. These documents are meant to be read by anyone who is interested in learning more about how RusTOS was created and its inner workings. They are also meant to be a reference for anyone who wants to contribute to RusTOS or create their own RTOS in Rust.
